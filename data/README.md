## Data


### Description
The dataset consists of central bank speeches from 1997 to 2025, collected from the Bank for International Settlements (BIS). Each observation includes the full speech text, the issuing institution, the issue date and a short text description.
All speeches are provided in English, as they are either originally delivered in English or translated into English.


### Source
- HuggingFace dataset: https://huggingface.co/datasets/samchain/bis_central_bank_speeches  
- Original source (BIS): https://www.bis.org


### Acknowledgements
The original data is provided by the Bank for International Settlements (BIS).
The dataset was made available on the HuggingFace Hub by Samuel Chaineau.


### Reproducibility
A local copy of the dataset is stored to ensure reproducibility of the results. (removed due to its size)

In addition, the file `custom_stopwords_bis.txt` was enriched using domain-specific terms, combining course materials + manual curation to improve preprocessing quality.
